PlantAI — ნამდვილი AI ჩატის ვერსია

ფაილები:
- index.html — საიტის გვერდი
- netlify/functions/chat.mjs — უსაფრთხო სერვერული ფუნქცია, რომელიც OpenAI API-ს უკავშირდება
- netlify.toml — Netlify-ის კონფიგურაცია

მნიშვნელოვანი:
API გასაღები არ ჩაწერო HTML/JavaScript ფაილში და არ გაუზიარო სხვას.
OpenAI API გამოყენება შეიძლება ფასიანი იყოს და ChatGPT-ის გამოწერისგან ცალკე ანგარიშდება. რადგან ანგარიშის შექმნა/გადახდა ასაკობრივ პირობებს მოიცავს, მშობელმა ან მეურვემ უნდა მართოს API ანგარიში, გასაღები და ხარჯების ლიმიტები.

გამოქვეყნება:
ეს პროექტი საჭიროებს Netlify Functions-ის მხარდაჭერით deploy-ს. უბრალო HTML-ის drag-and-drop ატვირთვა შეიძლება საკმარისი არ იყოს ფუნქციის ასამუშავებლად. გამოიყენე GitHub-თან დაკავშირებული Netlify deploy ან Netlify CLI.

Netlify-ში გარემოს ცვლადის დამატება:
Name: OPENAI_API_KEY
Value: [შენი API key — საიტის მფლობელმა შეიყვანოს პირადად]
შემდეგ გაუშვი ახალი deploy, რათა ფუნქციამ ცვლადი წაიკითხოს.
